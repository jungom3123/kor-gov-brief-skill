# Brief Deck 디자인 시스템

SKILL.md의 규칙을 바로 쓸 수 있는 값과 부품으로 옮긴 것이다.

| 파일 | 내용 |
| --- | --- |
| `tokens.json` | 색 26개(본문·네이비 두 테마), 글자 12단계, 간격·치수·모서리. 모든 값은 1920px 기준 |
| `tokens.css` | 위 토큰의 CSS 변수와 `t-*` 글자 클래스. `[data-theme="dark"]`가 네이비 슬라이드 |
| `brief-deck.css` | HTML 슬라이드 부품 13종(`bd-*` 클래스) |
| `components.md` | 부품별 쓰임·넣는 것·할 것/하지 않을 것·마크업 |
| `template/BriefDeck_template.pptx` | PowerPoint 템플릿. 레이아웃 5종(표지·간지·제목 바 본문·바 없는 본문·마무리) + 예시 10장, 테마 색·글꼴(맑은 고딕) 적용 |

HTML 덱: `tokens.css` 다음 `brief-deck.css`를 불러오고 슬라이드마다 `<section class="bd-slide">`를 둔다. 표지·간지·마무리는 `data-theme="dark"`.

pptx 덱: 템플릿을 복사해 예시 슬라이드를 고치거나, 같은 레이아웃으로 새 슬라이드를 추가한다. 테마 색 순서는 강조1 네이비, 강조2 블루, 강조3 하늘색, 강조4 회색, 강조5 포인트 레드, 강조6 노랑이다.


## 기본 원칙

- **한 장 한 메시지.** 제목 아래 핵심 문장 1줄(`t-headline`, KeyMessage)을 먼저 쓰고, 본문은 그 근거 2~4덩이로 채운다.
- **핵심어만 색.** 문장 전체가 아니라 단어 2~4개만 `accent`(`.bd-em`)로 칠한다. `primary` 띠 위에서는 `accent-inverse`.
- **숫자는 크고 단위는 작게.** `t-number`(120px) + 1/3 크기 단위(`.bd-num__unit`). 증감은 `signal` + ▲▼.
- **전은 회색, 후는 주색.** 전·As-Is는 `gray`·`surface-neutral`, 후·To-Be는 `primary`·`accent`·`surface-tint`. 사이에 화살표.
- **라벨은 알약.** 섹션 라벨·카드 헤더는 Pill(`radius-pill`, `primary` 채움, `on-primary` 글자).
- **장식은 한 종류.** 사선 액센트(`sky`), 대괄호, 점선 리더 중 덱마다 하나만. 그림자·그라데이션·형광 강조는 쓰지 않는다.

## 캔버스와 단위

모든 값은 1920×1080 슬라이드 기준 px다(`canvas-w`, `canvas-h`). PowerPoint·Keynote(13.33×7.5in)로 옮길 때는 **px ÷ 2 = pt**: `t-title` 58px → 29pt, `t-body` 32px → 16pt, `space-margin-x` 80px → 40pt.

- 좌우 여백 `space-margin-x`(80), 상하 `space-margin-y`(60), 본문 폭 `content-w`(1760).
- 블록 사이 `space-block`(36), 카드 사이 `space-card-gap`(32, 4열 이상은 `space-card-gap-dense` 26), 카드 안 `space-card-pad`(40).
- 카드·사진 모서리 `radius-card`(16), 라벨 박스·번호 박스 `radius-sm`(8), 알약 `radius-pill`.

## 색

두 테마는 슬라이드 종류다. **본문 슬라이드**(light)는 흰 배경에 네이비·블루, **네이비 슬라이드**(dark)는 표지·간지·마무리·결론 페이지에 쓴다. 같은 컴포넌트가 두 테마에서 그대로 동작한다.

- 주색 `primary`(#1D3466), 핵심어 `accent`(#2A70BE), 카드 배경 `surface-tint`, 본문 `ink`, 보조 글자 `ink-muted`, 괘선 `rule`.
- `signal`(코랄 레드)은 증감 숫자·합계·꼭 볼 한 곳에만, **한 장에 세 군데 이하**. 흰 배경 대비 3.5:1이라 24px 이상 굵은 글자에만 쓴다.
- `highlight`(노랑)는 어두운 배경 위 숫자·결론에만.
- 차트는 `chart-1`→`chart-4` 순서로, 4계열을 넘기지 않는다. 전·후 비교는 `chart-4`(전) → `chart-2`(후).
- 분류색이 필요하면 `cat-1`~`cat-4`. 같은 항목은 덱 전체에서 같은 색.
- `gray`와 `sky`는 표식 전용이다. 22px 미만 글자에는 `ink-muted`를 쓴다.
- **브랜드 색이 있는 고객사**: `primary`만 브랜드 색으로 바꾸고 `accent`는 그 색의 밝은 톤, 나머지는 그대로 둔다.

## 글자

글꼴은 Pretendard, 없으면 Noto Sans KR(Google Fonts), 그다음 시스템 고딕(`font-sans`). 굵기는 Bold(제목·숫자·핵심어)와 Regular(본문) 두 단계만.

| 자리 | 스타일 | px | pt |
| --- | --- | --- | --- |
| 표지 제목 | `t-cover` | 96 | 48 |
| 간지·목차 번호 | `t-section-no` | 160 | 80 |
| 간지 제목 | `t-section` | 88 | 44 |
| 페이지 제목 | `t-title` | 58 | 29 |
| 핵심 문장 | `t-headline` | 52 | 26 |
| 큰 숫자 | `t-number` | 120 | 60 |
| 카드 헤더·알약 | `t-card-head` | 36 | 18 |
| 본문 불릿 | `t-body` | 32 | 16 |
| 하위 불릿·※ | `t-body-sub` | 24 | 12 |
| 표 | `t-table` | 26 | 13 |
| 차트 라벨 | `t-chart` | 24 | 12 |
| 출처·단위·쪽번호 | `t-caption` | 20 | 10 |

22px(11pt) 미만은 `t-caption` 자리뿐이다.

## 그림과 아이콘

한 덱에 한 종류만: 플랫 라인 아이콘, 아이소메트릭 일러스트, 사진 중 하나(사진 + 라인 아이콘 조합은 허용). 사진은 같은 비율로 자르고 `radius-card`를 준다. 이 시스템에는 로고가 없다. 고객사 로고는 받은 파일만 쓰고 다시 그리지 않는다.

## HTML로 만들 때

`tokens.css`와 `components/bundle.css`를 불러오고, 슬라이드마다 `<section class="bd-slide">`(1920×1080 고정)를 둔다. 글자 크기는 `t-*` 클래스, 부품은 `bd-*` 클래스로 준다. 각 컴포넌트 문서에 마크업 예시가 있다.

## 만든 뒤 점검

- 핵심어 색이 한 장에 4곳 이하, `signal`이 3곳 이하인가
- 한 장에 표 1개, 차트 2개 이하인가
- 22px 미만 글자가 출처·단위·쪽번호뿐인가
- 한 줄 카드들의 간격·높이·안 여백이 같은가
- 같은 레이아웃을 3장 넘게 연속으로 쓰지 않았는가

## 하지 않는 것

- 문장 전체 색칠, 여러 색 형광 강조, 그림자·입체 효과
- 일러스트와 스톡 사진 섞기, 저해상도 캡처
- 4:3 비율, 22px 미만 본문
- 레퍼런스 원본의 정부 로고·기관명·사진·문구

## 레이아웃 16종

각 레이아웃은 아래 컴포넌트를 조합한다. 치수는 1920px 기준이다. 원본 사례 이미지는 `../references/layouts/`에 있다.

| # | 레이아웃 | 쓰는 컴포넌트 | 핵심 규칙 |
| --- | --- | --- | --- |
| 01 | 표지 | 네이비 슬라이드, `t-cover` | 좌측 정렬 + 우측 비주얼. 부제 → 제목 → 날짜·발표자 → 로고 순 |
| 02 | 목차 | Pill, `t-section-no` | 3~5항목은 가로 1열 번호 타일, 번호 70~200px, 항목명 40~44px |
| 03 | 간지 | 네이비 슬라이드, `t-section-no`, `t-section` | 번호·제목·소항목 세 덩이만. 좌우 45:55 분할 또는 전면 중앙 |
| 04 | 핵심 메시지 | KeyMessage, BigNumber, ConclusionBand | 헤드라인 1~2줄 → 좌 숫자 / 우 차트 → 하단 결론 띠 |
| 05 | 수치 카드 | StatCard | 카드 3~5개 1행. 전(회색 작게) → 후(블루 크게) + 증가율 배지 |
| 06 | 차트 | BarChart, Pill | 계열 2~3개, 값 라벨 전부, 가로 격자만, 단위 우상단. 옆에 결론 카드 1개 가능 |
| 07 | As-Is / To-Be | BeforeAfter | 좌 회색 → 우 주색. 라벨 쌍은 현행/개선, 현재/미래 등 |
| 08 | 카드형 과제 | TaskCard, KeyMessage | 3~4열(폭 400~480) 또는 2×2. 헤더 알약을 카드 위에 걸친다 |
| 09 | 구조 도식 | Pill, TaskCard | 비전 → 목표 → 전략 → 과제를 밴드 + 4열 카드로. 도형 안 글자 30~50px |
| 10 | 프로세스 | ProcessSteps | 가로 3~8단계, 주색·블루 교차, 아래 설명 박스 |
| 11 | 타임라인 | Timeline | 날짜 알약 + 제목 + 설명. 지난 일정은 회색 |
| 12 | 지도 | `surface-tint` 실루엣 | 권역은 주색 톤온톤 4~5단계. 지도 50% + 우측 결론 |
| 13 | 표 | DataTable | 한 장에 1개, 12행 넘으면 2단, 20행 넘으면 두 장. 위에 요약 1줄 |
| 14 | 상세 템플릿 | Pill, DataTable | 좌 라벨 열(폭 400) + 우 본문 반복. 여러 장에서 번호·이름만 바뀐다 |
| 15 | 사진·아이콘 카드 | `radius-card` 사진 | 4~5열(폭 310~355), 같은 비율 크롭, 설명 2~3줄 |
| 16 | 마무리 | 네이비 슬라이드 | "감사합니다" 110~150px 1개 + 메시지 1~3줄. 표지와 같은 계열 |

## 덱 구성

기본 순서는 표지 → 목차 → (간지 → 본문) × 장 수 → 마무리다. 10장 이하면 간지를 뺀다. 본문 첫 장은 결론(04 핵심 메시지)으로 열고, 근거(05·06·13) → 방향(07·08·09) → 실행(10·11·14) 순으로 간다. 같은 레이아웃은 3장 넘게 잇지 않고, 표·차트 다음에는 카드·도식을 둔다.
