# 발표 디자인 레퍼런스 활용

정부 R&D 설명회 발표자료(2020~2026년, PDF 283개)를 **디자인 참고용으로만** 분석해 정리한 규칙이다. 그중 32개 덱에서 고른 100장을 1800px 해상도로 한 장씩 보며 구도·여백·색·글자 크기·차트·표를 기록했고, 아래 규칙은 그 기록을 종합한 것이다. 원본의 정책 내용은 발표 주제와 무관하며 인용하지 않는다. 발표 주제·청중·참고자료는 사용자가 매번 따로 준다.

## 함께 들어 있는 자료

- `references/layouts/<번호_유형>/` — 유형별 좋은 사례 100장(가로 960px). 파일명 `<순번>_<연도>_<원본 파일명 일부>_p<쪽>.jpg`
- `references/README.md` — 100장 갤러리(출처·스타일 계열·유형별 핵심 규칙)
- `references/style-families.md` — 스타일 계열 6종의 특징과 대표 원본

이 폴더에 `references/`가 없으면(계정 스킬로만 저장된 경우) 갤러리는 https://github.com/jungom3123/kor-gov-brief-skill/blob/main/skills/rnd-reference-deck-style/references/README.md 에서 본다.

모든 치수는 **1920×1080px 기준**이다. pptx로 만들 때는 px ÷ 2 = pt (13.33×7.5in 슬라이드).

## 1. 스타일 계열 고르기

| 계열 | 이렇게 생겼다 | 어울리는 용도 |
| --- | --- | --- |
| **A. 네이비 정책형** | 네이비 제목 바 + 흰 본문, 핵심어만 블루, 큰 숫자 | 사내 보고, 전략 제안, 예산·성과 보고 |
| **B. 아이소메트릭 일러스트형** | 밝은 배경 + 입체 일러스트, 블루 그라데이션, 둥근 카드 | 고객사 제안, 포트폴리오, 서비스 소개 |
| **C. 다크 사진 키비주얼형** | 어두운 사진 전면 + 흰 굵은 제목, 본문은 흰 카드 | 키노트, 비전·전략 발표 |
| **D. 컬러 테마형** | 네이비 자리에 브랜드 색 하나(코랄·그린·보라), 나머지는 회색 | 브랜드 색이 있는 고객사 |
| **E. 표 중심 사업안내형** | 촘촘한 표·개조식, 좌측 라벨 열, 장식 최소 | 상세 페이지, 부록, 사업 안내 |
| **F. 인쇄 자료집** | 세로 A4, 카드 반복 | 출력용 포트폴리오 |

하나만 고른다. 한 덱 안에서 계열을 섞지 않는다. 다만 A·B·C는 **표지·간지·마무리는 C처럼 사진/일러스트로, 본문은 A처럼** 쓰는 조합이 레퍼런스에서 가장 흔하다.

## 2. 기본 틀

### 캔버스와 여백
- 16:9, 1920×1080. 좌우 여백 80px, 상하 여백 60px. 본문 폭 1760px.
- 제목 바(세 가지 중 하나, 덱 전체에서 통일):
  1. **전폭 네이비 바** 높이 110~150px(사진 오버레이 가능). 좌측에 번호 박스("01") + 위 작은 행사명(22px) + 제목(56~60px 흰). 우측 로고.
  2. **좌측 짧은 바** 폭 500~650px, 높이 100px, 오른쪽 끝 사선 + 하늘색 액센트. 로마숫자 + 제목(60px 흰).
  3. **바 없음** — 좌상단 작은 회색 장 표시(22px) + 네이비 제목(56~60px) + 밑줄 또는 좌측 세로 회색 탭. 공간이 넓어 도식·차트 페이지에 좋다.
- 제목 아래 **소제목/핵심 문장** 1줄: 라벨 박스(네이비, 흰 글자 32~36px) + 문장(40~56px, 핵심어만 블루). 또는 전폭 알약 밴드(네이비, 흰 40px).
- 하단: 쪽번호(우하단 18~22px 회색 또는 알약), 출처·단위(좌하단/우상단 18~22px 회색). 풋터 행사명은 선택.
- 본문 블록 간격 30~40px. 카드 간격 30~40px(열 4개 이상이면 25~30px). 카드 모서리 12~20px. 카드 안 여백 36~48px.

### 글자 크기(px, 1920 기준)
| 자리 | 크기 | 비고 |
| --- | --- | --- |
| 표지 제목 | 80~110 | 화면 높이의 7~10%. 부제 24~60 |
| 간지 번호 | 90~250 | 가장 큰 그래픽. 간지 제목 80~110 |
| 목차 번호 | 70~200 | 항목명 40~44 |
| 제목 바 | 56~60 | 위 작은 장 표시 22 |
| 헤드라인(핵심 문장) | 44~60 | 1~2줄. 핵심어만 색 |
| 큰 숫자 | 60~150 | 단위는 숫자의 1/3 크기 |
| 카드 헤더 | 32~40 | 알약·밴드 안 흰 글자 |
| 본문 불릿 | 28~36 | 하위 불릿 22~26 |
| 표 | 22~30 | 헤더 24~30 |
| 차트 라벨 | 22~30 | 축 18~24 |
| 출처·단위·쪽번호 | 18~22 | 회색 |

글꼴: 굵은 고딕 제목 + 고딕 본문(Pretendard, Noto Sans KR 등). 굵기는 Bold(제목·숫자·핵심어)와 Regular(본문) 두 단계만. 표지에서 가는 제목 1줄 + 굵은 제목 1줄 대비는 허용. 캘리그래피·필기체는 마무리나 간지 번호에만.

### 색
- 기본(계열 A·B·C): 네이비 `#1D3466` · 블루 `#2A70BE` · 하늘색 `#8FC1F2`(어두운 배경 위 핵심어) · 카드 배경 `#EAF1FA` · 회색 `#8A94A6`(전/As-Is/비강조) · 괘선 `#D6E0EE` · 본문 `#1F2937`
- 포인트 레드 `#E1614F` — 증감 숫자, 핵심어, 합계 행에만. 한 장에 세 군데 이하.
- 노랑 `#FFD400` — 어두운 배경 위 숫자·결론 강조에만.
- 차트 팔레트(순서대로): 네이비 → 블루 → 하늘색 → 회색. 전·후 비교는 회색(전) → 블루(후). 4계열 넘기지 않는다.
- 분류별 색이 필요하면 같은 채도의 4색(예: 올리브 `#5B7B3A`, 청록 `#1E8A86`, 블루 `#2A70BE`, 보라 `#6657B5`)을 쓰고, 같은 항목은 덱 전체에서 같은 색.
- 계열 D는 네이비 자리에 브랜드 색을 넣고 블루 자리에는 그 색의 밝은 톤, 나머지는 회색. 계열 E는 헤더만 색, 본문은 흰·연회색.
- 배경은 흰색 또는 연회색/연하늘 그라데이션. 어두운 배경(네이비·사진)은 표지·간지·마무리·결론 띠에만.

## 3. 공통 문법(100장에서 반복된 장치)

- **한 장 한 메시지.** 제목 아래 핵심 문장 1줄을 두고, 본문은 그 근거 2~4덩이.
- **핵심어만 색.** 문장 전체가 아니라 단어 2~4개만 블루(어두운 배경에서는 하늘색·노랑).
- **숫자는 크고 단위는 작게.** 60~150px 숫자 + 1/3 크기 단위. 증감은 포인트색 + 화살표(▲ ▼ ↑).
- **전 → 후.** 회색(전) → 주색(후) + 화살표. As-Is는 회색 밴드/박스, To-Be는 네이비·블루 밴드/박스. 전·후 접합은 사선 또는 화살표.
- **라벨은 알약.** 섹션 라벨·카드 헤더는 둥근 알약(주색, 흰 글자). 카드 위에 반쯤 걸치면 더 좋다.
- **결론 띠.** 페이지 하단 전폭 네이비 띠(높이 190~230px) 또는 큰 대괄호 [ ] 안 1줄에 결론.
- **불릿은 체크·▶·●.** 하위는 –, ※. 한 덩이 6줄 이내.
- **번호를 그래픽으로.** 간지·목차·카드의 번호는 본문의 2~3배 크기, 회색+주색 2톤이나 이탤릭도 가능.
- **장식은 한 종류.** 사선 액센트, 얇은 ㄱ자 코너, 점선 리더 중 하나만. 여러 색 형광 강조, 그림자 남발 금지.
- **그림은 한 톤.** 아이소메트릭 일러스트·플랫 아이콘·사진 중 한 덱에 한 종류(사진 + 라인 아이콘 조합은 허용).

## 4. 레이아웃 16종

각 유형의 사례는 `references/layouts/<번호_유형>/`에 있다. 괄호는 그 유형의 사례 수.

**01 표지 (10)** — 제목 80~110px. 좌측 정렬 + 우측 비주얼(10장 중 7장) 또는 전면 배경 + 완전 중앙. 위에서 아래로 부제/라벨 → 제목 → 날짜·발표자 → 로고. 전면 사진이면 글자는 한쪽에 몰고 반대쪽은 비운다. 둥근 카드 안에 글자를 넣고 바깥을 색·사진으로 채우는 변형도 있다.

**02 목차 (6)** — 항목 3~5개면 가로 1열, 번호 타일(170px 연하늘 사각 또는 지름 270px 원)에 번호 70~200px + 항목명 40~44px. 하위 항목이 있으면 세로 목록 또는 2단, 번호 2톤. 상단 밴드(높이 28%) 또는 좌측 1/3 패널에 "Contents". 2파트 구조면 흰 라운드 카드 안 2단.

**03 간지 (7)** — 글자 2~3덩이(번호·제목·소항목)만. 번호 90~250px. 구성은 (a) 전면 단색·사진 + 중앙 정렬 (b) 좌우 분할(색 블록 45% + 흰 영역에 소항목) (c) 상하 분할(그림 55~70% + 색 띠). 상단에 장 이름 네비게이션(현재 장만 흰 굵게)을 두면 긴 덱에 좋다. 장마다 배경색을 바꿔도 된다.

**04 핵심 메시지·수치 강조 (6)** — 헤드라인 1~2줄(44~90px, 핵심어 블루) 중앙 또는 좌상단. 아래 좌 메시지+큰 숫자 / 우 차트(또는 2~3단). 하단 결론 띠·대괄호·블루 밴드로 1줄 마무리. 사선 밴드 2개(블루·네이비)에 흰 굵은 글자를 넣는 변형.

**05 수치 카드 (6)** — 카드 3~6개(1행 3~5개 또는 2행). 카드 = 색 헤더(알약·밴드) + 아이콘 + 숫자 40~110px + 단위 작게 + 설명 1~2줄. 전·후는 회색 작은 값 → 블루 큰 값 + 증가율 배지. 연도별 패널 3개 + 사이 화살표(증가율) 구성도 좋다. 카드 아래 표 1개 가능(합계 행 블루, 신규 열 빨강 테두리).

**06 차트 (7)** — 계열 2~3개. 전(회색)→후(주색) 쌍 막대가 가장 흔하고, 10년 추세는 마지막 해만 주색. 값 라벨은 전부 표기(22~30px). 범례 대신 선 끝 색 라벨 박스. 격자는 흐린 가로선만. 증가율은 포인트색 + 화살표. 차트 제목은 알약/리본, 단위는 우상단 작게. 차트 옆에 결론 카드(네이비 라벨 + 전→후 숫자 + 3줄 리스트) 또는 표 1개. 도넛은 지름 700px 이상, 중앙에 총액, 조각 색은 단색 톤 8단계 이하.

**07 As-Is / To-Be 비교 (6)** — 좌(전, 회색·연한 색) → 우(후, 주색·진한 색) 또는 상(전)/하(후). 접합은 사선·화살표·말풍선. 라벨 쌍: As-Is/To-Be, 기존/개정, 현행/개선, 현재/미래. 비교 아래 3열이면 각 열에 번호 + 세로 점선 구분. 실제 사진(전) ↔ 콘셉트 이미지(후) + 중앙 라벨 화살표 변형.

**08 카드형 전략과제 (7)** — 카드 3~5개. 1행이면 3~4개(폭 400~480px), 2행이면 2×2(800×340px) 또는 3+2 중앙 정렬. 카드 = 색 헤더(알약·밴드·그라데이션, 32~40px 흰) + 흰/연회색 본문 + 불릿 2~4개(28~30px, 핵심어 색) + ※ 보충(22px). 헤더 색은 서로 달라도 같은 채도. 카드 위에 라벨 박스 + 헤드라인 1줄. 상단에 일러스트(높이 180px)를 올린 4열 카드 변형.

**09 구조 도식·체계도 (7)** — 위→아래(비전→목표→전략→과제)는 밴드/알약 + 삼각 연결 + 4열 카드. 중심↔주변은 중앙 원(420px) + 주변 원 3~4개(330px) + 방사선 + 바깥 리스트. 상호작용은 순환 화살표(300px) + 좌우 카드. 계층은 피라미드(위로 갈수록 연한 색, 5단). 도형 안 글자 흰 30~50px, 바깥 리스트 24~36px.

**10 프로세스·단계 (6)** — 가로 3~8단계. (a) 쉐브론 블록(190×160px, 네이비·연하늘 2톤 반복, 흰 40px) (b) 원(220px, 점점 진한 블루) + 회색 화살 밴드 (c) 사진 타일(260×150px) + 노랑 큰 번호 + 열 사이 화살표. 단계 아래 설명 박스(흰 테두리 제목 28px + 회색 설명 20px) 세로 체인. 세로 프로세스는 좌 네이비 라벨 박스 + 우 점선 박스(사업 안내용).

**11 타임라인·일정 (6)** — (a) 가로 축 + 흰 원 마커, 연도 36px 네이비 위아래 교차(연혁) (b) 날짜 알약(180×70px 네이비) + 제목 36px + ≫ 설명 2×2(경과) (c) 월별 12열 표(연간 일정) (d) U턴 트랙 회색 밴드 60px + 색 헤더 박스 6개(360×180px) (e) 가로 띠 행 7개(1660×110px, 완료 행만 색 그라데이션). 날짜는 알약 안 흰 글자 또는 굵은 네이비.

**12 지도 (3)** — 지도는 연한 실루엣(회색·연하늘). 권역은 주색 톤온톤 4~5단계 + 네이비 원 라벨(110px). 데이터 마커는 흰 원(크기 ∝ 값) + 바깥 라벨. 지도 50% + 우측 결론 블록(ㄱ자 코너 + 제목 50px + 체크 불릿) 또는 지도 2장 비교. 인포그래픽형은 참고/부록에만.

**13 표 (6)** — 한 장에 표 1개. 헤더는 주색 흰 글자 또는 연한 주색 검정 글자(24~30px). 본문 22~30px. 세로 괘선 없애거나 연하게, 가로 괘선 얇은 회색 또는 줄무늬. 합계·소계 행은 연살구·연회색 + 빨강 숫자 또는 빨강 테두리. 강조 열 연노랑, 강조 행 연녹·연하늘, 신규는 NEW 배지. 단위 우상단. 12행 넘으면 2단으로, 20행 넘으면 두 장으로. 표 위에 요약 문장 1줄(블루 40px).

**14 사업 상세 템플릿 (7)** — 좌 라벨 열(또는 연회색 패널 폭 400px: 번호 80px + 사업명 40px + 아이콘) + 우 본문 반복. 섹션 라벨은 알약(24~36px). 본문 28~34px, 표 20~24px. 같은 템플릿을 여러 장 반복할 때는 번호와 사업명만 바뀐다. 큰 흰 라운드 카드(1700×950px) 안에 3행(라벨 | 본문)으로 묶는 변형.

**15 사진·아이콘 카드 (6)** — 사진은 같은 비율로 자르고(정사각·4:3·16:9 중 하나) 라운드 12~20px. 열 4~5개(폭 310~355px). 제목은 사진 위 색 탭/알약 또는 아래 라벨 밴드, 설명 2~3줄 26~30px 회색 박스. 큰 사진 2장 + 흰 원 포인터 + 점선 리더 → 하단 라벨 변형. 아이콘 리스트는 원 아이콘(100px, 3톤 번갈아) + 제목 34px + ▶ 설명 24px, 2×5.

**16 마무리 (4)** — "감사합니다/THANK YOU" 110~150px 1개 + 메시지 1~3줄 40~60px(핵심어 블루). 배경은 표지와 같은 계열. 연락처는 반투명 검정 박스에 26px. 캘리그래피 한 줄 메시지만으로 끝내는 변형.

## 5. 덱 구성

- 기본 순서: 01 표지 → 02 목차 → (03 간지 → 본문)×장 수 → 16 마무리. 10장 이하면 간지 생략.
- 본문 첫 장은 04 핵심 메시지(결론 먼저), 이어서 근거(05·06·13), 방향(07·08·09), 실행(10·11·14), 보강(12·15).
- 같은 유형을 연속 3장 이상 쓰지 않는다. 표·차트 페이지 다음에는 카드·도식 페이지를 둔다.
- 10장 예시: 표지 / 목차 / 핵심 메시지 / 수치 카드 / 차트 / As-Is·To-Be / 카드형 과제 / 프로세스 / 일정 / 마무리.

## 6. 작업 순서

1. 주제·청중·참고자료로 용도를 정하고 §1에서 계열 하나를 고른다. 브랜드 색을 받으면 D 방식으로 네이비만 교체.
2. 슬라이드 구성안을 짜고 페이지마다 레이아웃 유형(01~16)을 지정한다. 페이지마다 핵심 문장 1줄을 먼저 쓴다.
3. 쓸 유형의 `references/layouts/` 이미지를 열어 구도·여백·위계만 본다. 내용·그림·로고·문구는 가져오지 않는다.
4. §2~4 치수로 만든다. HTML이면 `.slide{width:1920px;height:1080px}` 고정, pptx면 px÷2 pt. 글꼴이 없으면 시스템 고딕으로 대체.
5. 만든 뒤 점검: 핵심어 색이 한 장에 4개 이하인가, 포인트 레드가 3곳 이하인가, 한 장에 표가 1개인가, 글자 22px 미만이 출처·단위뿐인가, 카드 간격이 같은가.

## 7. 하지 않는 것

- 한 장에 표 두 개, 차트 세 개 이상
- 여러 색 형광 강조, 문장 전체 색칠, 그림자·입체 효과 남발
- 아이소메트릭 일러스트와 스톡 사진 혼용, 저해상도 캡처 삽입
- 4:3 비율, 글자 22px(11pt) 미만의 본문
- 레퍼런스의 정부 로고·기관명·사진·문구를 결과물에 넣는 것
