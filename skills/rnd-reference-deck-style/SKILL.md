# 발표 디자인 레퍼런스 활용

정부 R&D 설명회 발표자료(2020~2026년, PDF 283개)를 **디자인 참고용으로만** 분석해 정리한 규칙이다. 원본의 정책 내용은 발표 주제와 무관하며 인용하지 않는다. 발표 주제·청중·참고자료는 사용자가 매번 따로 준다.

## 함께 들어 있는 자료

- `references/layouts/<번호_유형>/`: 유형별 좋은 사례 페이지 이미지 (13개 유형)
  - 01_표지, 02_목차, 03_간지, 04_핵심메시지_수치강조, 05_수치카드, 06_AsIs_ToBe_비교, 07_카드형_전략과제, 08_구조도식, 09_타임라인_일정, 10_지도, 11_표, 12_사진활용, 13_마무리
  - 파일명 규칙: `<순번>_<연도>_<원본 파일명 일부>_p<쪽>.jpg`
- `references/style-families.md`: 스타일 계열 6종의 특징과 대표 원본

## 스타일 계열 → 용도

| 계열 | 특징 | 어울리는 용도 |
| --- | --- | --- |
| A. 네이비 정책형 | 네이비 제목 바, 흰 배경, 큰 숫자 강조 | 사내 보고, 전략 제안 |
| B. 아이소메트릭 일러스트형 | 밝은 배경 + 입체 일러스트, 블루 그라데이션 | 고객사 제안, 포트폴리오 |
| C. 다크 사진 키비주얼형 | 어두운 전면 이미지 위 흰 굵은 제목 | 키노트, 비전 발표 |
| D. 컬러 테마형 | 브랜드 색 하나(코랄, 그린 등)를 포인트로 | 브랜드 색이 있는 고객사 |
| E. 표 중심 사업안내형 | 촘촘한 표와 개조식 | 상세 페이지, 부록 |
| F. 인쇄 자료집 | 세로 A4, 사례 카드 반복 | 출력용 포트폴리오 |

## 기본 디자인 규칙

- 16:9 (1920×1080), 좌우 여백 80px, 상단 제목 바 약 110px
- 주색 네이비 `#1D3466` · 보조 블루 `#2A70BE` · 카드 배경 `#EAF1FA` · 포인트 레드 `#E1614F`(숫자·키워드에만)
- 굵은 고딕 제목, 고딕 본문(예: Pretendard). 표지 40 · 간지 36 · 제목 바 24 · 핵심 메시지 20 · 본문 14~16 · 출처 10pt
- 구조: 표지 → 목차 → 장 간지 → 본문 → 마무리. 본문은 제목 바 → 핵심 문장 1줄 → 2~3단 → 출처·쪽번호
- 한 페이지 한 메시지, 개조식 6줄 이내, 큰 숫자 + 작은 단위
- 피할 것: 한 장에 표 두 개, 여러 색 형광 강조, 일러스트·스톡사진 혼용, 4:3 비율

## 작업 순서

1. 사용자에게 받은 주제·청중·참고자료로 용도를 정하고, 위 표에서 계열 하나를 고른다(고객이 브랜드 색을 주면 D 방식으로 포인트색만 교체).
2. 슬라이드 구성안을 짠 뒤 페이지마다 레이아웃 유형(01~13)을 지정한다.
3. 필요한 유형의 `references/layouts/` 이미지를 직접 열어 구도·여백·위계를 참고한다. 내용과 그림은 베끼지 않고 배치만 참고한다.
4. 위 디자인 규칙으로 제작한다. 슬라이드 도구가 있으면 그것을, .pptx를 요청받으면 pptx로 만든다.
5. 레퍼런스의 정부 로고·기관명·문구·사진은 결과물에 넣지 않는다.
